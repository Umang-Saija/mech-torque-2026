# Mech Torque 2026 — Industrial Valve Gearbox 3D Showcase

An interactive, high-performance 3D web showcase for **Mech Torque** industrial quarter-turn worm gear operators (MT-20 to MT-60) manufactured in Rajkot, Gujarat. Built with Three.js, vanilla CSS, and modern web standards.

🌐 **Live Demo:** [https://mech-torque-2026.vercel.app](https://mech-torque-2026.vercel.app)

---

## ✨ Key Features

- **Interactive 3D Exploded Assembly**:
  - Stage-by-stage cinematic explosion and assembly of the MT-30 flagship gearbox (worm shaft, bronze/ductile gear wheel, casing, top cover, pointer indicator, handwheel, and fasteners).
  - Smooth scrub and stage jumping controls.
  - Optical color beam highlighter that precisely pinpoints active components in 3D space.

- **Dual Design Aesthetic**:
  - Architectural daylight frosted glass hero view with floating liquid-glass capsule navbar.
  - Dark luxury aerospace bento matrix for engineering specifications, materials, and models.

- **Complete Technical Specifications**:
  - Real-time CAD spec card tracking torque rating, gear ratio, flange standard (ISO 5211 F07/F10/F12), bore diameter, and material grades (IS 210 FG 200, SGI 500/7, 45C8 steel).
  - Models catalogue from 250 Nm to 2,000 Nm.

- **Responsive Mobile HUD**:
  - Mobile-first bottom HUD card with tactile buttons (Exploded, Drive Mesh, Assembled, Specs) and bottom stage indicator track.
  - Quick contact direct actions (Call, WhatsApp, Models, RFQ).

---

## 🛠️ Tech Stack

- **Core**: Vanilla HTML5, modern CSS3 (Custom Properties, Glassmorphism, CSS Grid & Flexbox)
- **3D Graphics**: Three.js
- **Typography**: Space Grotesk, Plus Jakarta Sans, JetBrains Mono, Barlow Condensed
- **Deployment**: Vercel

## 🚀 Local Development

To run locally:

```bash
# Clone the repository
git clone https://github.com/Umang-Saija/mech-torque-2026.git

# Navigate into the folder
cd mech-torque-2026

# Start a local static server
npx serve .
# or
python -m http.server 3000
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
